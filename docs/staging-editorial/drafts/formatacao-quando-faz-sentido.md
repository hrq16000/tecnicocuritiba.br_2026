# Intenção
Ajudar a decidir entre corrigir configuração, reparar o sistema, reinstalar o Windows ou formatar a unidade.

# Lacuna atual
“PC lento”, “erro” ou “vírus” não indicam automaticamente que formatar seja melhor.

# Proposta editorial
Formatação pode fazer sentido quando a causa é predominantemente software, existe backup verificável e hardware foi considerado saudável. Pode não resolver falha de SSD/HDD, RAM, temperatura, alimentação ou defeito físico. Reparo de sistema e correção de inicialização são alternativas menos destrutivas. Antes, confirme dados, licenças, drivers, aplicativos e configurações. Sem backup, com falha de armazenamento ou arquivos únicos, priorize preservação.

# Segurança e limites
Não recomendar formatar como resposta universal para lentidão, tela azul ou malware. Registrar o que será perdido antes da decisão.
