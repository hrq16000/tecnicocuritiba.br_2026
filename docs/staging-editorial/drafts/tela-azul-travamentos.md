# Proposta editorial
Lentidão responde devagar; travamento deixa de responder; reinicialização retorna automaticamente; desligamento perde energia; tela azul interrompe com código. Registre código, aplicativo, frequência e alterações recentes. Driver, memória, armazenamento, sistema, temperatura e hardware são categorias possíveis; nenhuma é confirmada só pela tela azul. Salve dados quando possível e evite trocar peças por associação ao código.

# Segurança e limites
