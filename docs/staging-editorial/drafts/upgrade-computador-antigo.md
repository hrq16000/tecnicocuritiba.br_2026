# Intenção
Decidir entre atualizar, reparar ou substituir sem usar idade isoladamente.

# Lacuna atual
Conteúdo auxiliar usa “antigo” como critério automático para troca.

# Proposta editorial
Upgrade pode fazer sentido quando o gargalo é identificável, há compatibilidade, estado geral confiável e uso pretendido cabe à plataforma. Reparo pontual é diferente de limitação de desempenho; degradação geral, peças indisponíveis, recorrência e risco aos dados podem tornar substituição mais racional. Considere custo real, expansão, confiabilidade e valor dos arquivos, sem inventar vida útil ou preço.

# Segurança e limites
Não recomendar troca por idade isolada. Preserve dados antes de abrir, migrar ou reinstalar.
